# Colors (Barry Pack)

Color palette tools for generating, expanding, and scoring color palettes.

## Tools

- `random_colors` — Get random color palettes from ColorHunt
- `contrasting_colors` — Generate contrasting colors from a base hex color
- `expand_palette` — Expand an existing palette to more colors by interpolation
- `score_palette` — Score a palette on contrast (WCAG), harmony, and distribution (0–100)
- `all_colors` — Fetch all color palettes from ColorHunt
